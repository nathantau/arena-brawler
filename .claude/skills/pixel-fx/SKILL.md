# Pixel-art effect strip

Effects are horizontal strips of square frames generated by `tools/sprites/generate.py` into
`assets/fx/<name>.png` and drawn by `SpecialFx` (one per Player, top-level, z 1) at the characters'
pixel scale. Never draw effects with smooth `draw_circle`/`draw_arc` shapes — the user wants pixel art.

## Rules

- Palette colours only (`palette.py`), hard alpha, outlined with `outline()`, nothing touching the
  frame edge (`check()` enforces all of this; `bolt` is the one strip exempt from the edge check).
- Frame = a `Canvas(size)` (any size; 48 small, 64-80 big; 1 art px = `Constants.SPRITE_SCALE` world px).
- Overlapping blobs that read as one mass go in **one** `part()` (lambda drawing several ellipses).
  Draw a second `part()` on top (e.g. the core of a cloud) to get an inner outline that separates lumps.
- Uneven, not symmetric: jitter angle / reach / radius per lump with `random.Random(<seed>)` seeded
  the same for every frame of the strip, so lumps stay consistent while animating.
- "Premium" shape of a one-shot: **anticipation → peak → follow-through.** E.g. poof (10 frames):
  swell up over 3 frames, hold full, burst outward + drift up, thin into trailing wisps and dots.
  Six frames or fewer looks cheap; aim for 8-12 for one-shots, 4 (period-4) for loops.
- Frame count is read from the texture (`width / height`) in Godot — don't hard-code it.

## Steps

1. Write `def <name>_frame(k, ...) -> Image.Image` near `poof_frame` in generate.py (normalised time
   `t = k / (N - 1)`; phases as above). Register a lambda in `FX` building `strip([...])`.
2. Run `tools/sprites/.venv/bin/python tools/sprites/generate.py`.
3. **Look at it**: paste the strip over a mid-blue background, resize x4 NEAREST, save to the
   scratchpad, Read it. Iterate until each phase reads.
4. Play it in `scripts/player/special_fx.gd`:
   - `preload` the texture as a const.
   - One-shot at a spot: `_poof(at, ART, duration)` (any strip works; it plays once, frame from `t/duration`).
   - Loop anchored to skill state: copy the smoke pattern (`_smoke_t`, `SMOKE_FPS`, drawn in `_draw`).
   - Trigger from **synced state changes** in `sync()` (`was_x and not x` style), never from input or
     RPCs, so remote players and replays show the same thing. Cosmetic randomness uses `_rng`, never
     the sim's RNG.
   - To follow a moving player, spawn at `p.global_position + p.visual_offset` at the moment it should
     start (spawn from `_process` when a timer crosses a threshold) rather than a delayed poof.
5. `godot --headless --import`, run GUT (all pass).
6. Preview in game: `godot --path . --write-movie <scratch>/run/f.png --fixed-fps 30 --quit-after 270 -- --offline --autopilot --touch --arena 2 --character <id> --special <skill_id>`
   (autopilot uses the special at sim frame 420 = movie frame ~210; use a new dir per run, `rm -rf $VAR`
   is blocked). Make a contact sheet of frames ~204-230 and Read it, then a GIF (Pillow, crop
   `(0, 0, 800, 450)` if the player is top-left, NEAREST resize, `duration=33`).
   For world effects in `scripts/fx/effects.gd` (blast / slam / slash, beams, particles) use the side-by-side
   preview instead: add the new effect to `tools/fx_preview.gd`, then
   `godot --path . --write-movie <scratch>/pv/f.png --fixed-fps 30 --quit-after 30 -s tools/fx_preview.gd`.
7. Update the FX line in CLAUDE.md Status, commit, send the user the GIF.
